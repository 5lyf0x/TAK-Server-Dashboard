# Changelog

## github-final-8091

Packaged the final GitHub launching-point build with complete documentation.

Main features:
- GitHub-safe generic defaults with no private infrastructure data
- Port 8091
- Service name `tak-server-dash.service`
- Dashboard UI for ZeroTier peers, monitored services, and banner warning choices
- Default monitored services: opentakserver, eud_handler_ssl, rabbitmq-server
- WiFi/HaLow reception shows `Not connected` in a smaller label style when disconnected
